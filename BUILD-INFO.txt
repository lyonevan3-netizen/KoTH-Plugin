KoTH 1.5.1 source package

Based on the 1.5.0 Robblestone KoTH source.
Preserves the existing command set, per-arena editor, multiple arenas, rewards,
weekly schedules, hourly restarts, BossBars and PlaceholderAPI expansion.

1.5.1 maintenance changes:
- Combines the KoTH tick and schedule check into one repeating heartbeat.
- Caches leaderboard ordering and invalidates it only when a win is recorded.
- Batches stats.yml writes (every 60 seconds) and flushes on plugin shutdown.
- Adds %koth_next_event_seconds% and %koth_next_event_minutes% for numeric
  sidebar formatting; existing %koth_next_event% remains human-readable.

Compatibility target: Paper/Purpur 1.21.4, Java 21.
Build: GitHub Actions workflow in .github/workflows/main.yml (Maven package).
This is a source package; it has not been compiled or server-tested in this session.
